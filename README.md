Project Description Shelf & Soul is a Smart Book Club platform that allows users to search for books, generate smart summaries using AI, read daily inspirational quotes, check the campus weather for in-person meetings, and generate VIP meeting tickets.

APIs Used in this Project:

OpenLibrary API: To search and fetch book details.
Open-Meteo API: To check the current weather in Birzeit.
DummyJSON API: To fetch random daily quotes.
Google Gemini AI API: To generate Arabic summaries for the selected books.
Instructions to Run the Project

Clone the repository or download the files.
Navigate to the assignment1 folder.
Simply open the index.html file in any modern web browser (e.g., Google Chrome, Microsoft Edge). No backend servers or Node.js installations are required as this is a pure frontend application consuming REST APIs using Axios and Fetch.
Note: An active internet connection is required to fetch data from the APIs.
